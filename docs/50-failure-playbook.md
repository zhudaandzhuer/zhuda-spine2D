# 50 症狀 → 根因

先分類，再動手。修最高影響的一個根因，保留前後對照。

| 看到的現象 | 先查 | 優先修法 | 不要做 |
|---|---|---|---|
| 能播但不像這個角色 | 等高原圖對照：頭身比、臉、手掌 | 回 `art.py`／原圖修造型（ART） | 加骨頭、加動畫、換好看的背景 |
| setup 與 key art 不一致（fidelity 有色塊） | 該 part 的 owner、manifest 座標、slot 順序 | 修歸屬／座標／順序 | 用 deform 或位移硬拉回去 |
| 抬手／轉頭露出硬切邊、別的部位殘色 | 該 part 單獨看：底層像素有沒有畫 | 補畫完整隱藏區 | 加遮罩、縮小動作幅度 |
| 多一隻手／多一個袖口 | 殘留 slot、setup attachment、同一元素畫在兩個 part | 清歸屬（OWNERSHIP） | 用變形把多的壓到看不見 |
| 骨頭在動、畫面沒動 | 該像素其實畫在別的 part（例如袖帽畫在身體上） | 修 owner 或讓該 part 共享權重場 | 繼續加大骨頭振幅 |
| 關節像紙片折、肘部尖角 | 過渡區權重寬度（`blend`）、網格格數 | 加寬 blend、沿彎曲方向加格 | 全身加密網格、再加一根骨 |
| 尖刺、翻面（check 報 flips） | 哪個 part、哪個時間（`check-sweep.json` details） | 修該區權重／降低該骨幅度／加格 | 反轉所有三角形 winding |
| 閉眼時透出眼珠 | 眼皮補片在眼眶上方是否不透明、羽化帶是否會移動 | 羽化帶固定，以下不透明並沿用臉部陰影 | 加大眼皮位移 |
| 眨眼／表情疊上去先抖一下 | overlay 首尾值 ≠ 底層休息值；mix-in 時間 | overlay 從休息值出發並回到休息值 | 把 mix 全設 0 |
| 歪頭時頭髮整束跟著轉 | 根骨 `inherit`、上端權重交給 `head` 的寬度 | 根骨 `noRotationOrReflection` ＋ `root="head"` | 在每個動畫手動反轉 |
| 轉頭像整張臉平移 | 深度場：臉皮用了 `W.depth` 嗎、五官 mix 是否隨位置不同 | 同一個橢球深度場給臉、頭頂、五官 | 只移動五官 |
| loop 每圈頓一下 | check 的 seam；`period` 是否整除 duration | 改成可整除的週期；首尾 key 一致 | 只讓第一格等於最後一格 |
| 頭髮物理亂甩、打結 | `physics.maxOffsetPx`、keyed 擺幅與物理是否疊加過頭 | 降 keyed 幅度／`inertia`，升 `damping` | 關掉物理就交付（沒說明） |
| 單一動畫正常，切換時破圖或半透明 | `spk play` 重現；兩 clip 是否 key 了互斥的 attachment／alpha | bridge、共同進度、或契約限制不可達狀態 | 把幾何檢查通過當成透明度通過 |
| 腳高度正確但滑步 | 接地點世界速度、root motion 是否重複 | 支撐段速度匹配＋Hermite 回擺 | 只報 IK 誤差 |
| 白邊／灰邊／黑邊 | 單件在深淺底、atlas `pma` 與材質混合是否一致、bleed | 修 alpha 邊或材質設定（MATERIAL） | 一律腐蝕 alpha |
| 原圖乾淨，縮小才出黑點 | 透明像素 RGB、filter／mipmap、padding、鄰區 | 依 runtime 取樣條件處理 | 重畫其實沒問題的圖、重建骨架 |
| 掌心該是手背、拇指方向錯 | 側別表、該手每個階段該露哪一面 | 補正確表面的美術 | 鏡射／負 scale 冒充 |
| 手掌忽大忽小 | 用掌寬與腕口配準了嗎 | 以解剖區段配準 | 用 bbox 或腕到指尖總長對齊 |
| 重建後修正消失 | 腳本讀的是哪個基底 | 固定基底、依序套用、輸出到新目錄 | 憑檔名新舊重跑整串 |
| 工具說成功但檔案不在 | 實際路徑與內容 | 以落地檔為準 | 把成功訊息當交付 |

## 三個最會浪費時間的假陽性

1. **局部數字放大成整體品質。** 某區 RGB 誤差很低，只證明那一區。
2. **數值通過放大成沒有可見問題。** 零翻面的角色仍可能有美術殘片、穿幫、難看的節奏。
3. **專用路徑通過放大成任意混合都安全。** 某個控制器路徑驗過，不代表任意兩 clip 直接 mix 沒事；要嘛帶走控制器，要嘛把任意混合也驗過。
