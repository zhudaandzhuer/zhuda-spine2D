# 40 驗證：每個檢查能證明什麼

把「某一層通過」寫成「角色完成」是最常見的錯。六層各自記錄；沒做的寫 `UNVERIFIED`。

| 層 | 工具 | 能證明 | 不能證明 |
|---|---|---|---|
| 檔案／結構 | `spk check`（static）、`spk util audit` | JSON 可解析、引用齊全、圖集區域存在、頁面是 RGBA | 角色長得對 |
| Runtime／幾何 | `spk check`（sweep） | 官方 runtime 可載入、頂點有限、無翻面／塌陷、權重和為 1 | 沒有貼圖殘邊、遮擋正確 |
| 動作數值 | `spk check`（loop seam、physics、mix、gait）、`spk util smooth` | loop 位置接上、速度跳變量、物理不發散、兩兩混合無翻面、落地腳不滑（契約有 `speed`＋`feet` 時） | 表演自然 |
| 美術對位 | `spk fidelity` | 原生 setup 重現 key art（座標、UV、權重編碼、層序） | 動起來之後的樣子 |
| 視覺 | `spk stress / sheet / play / shot / compare` + **你看圖** | 你實際看過的那些時間點與鏡頭 | 沒看過的時間點、其他平台 |
| 目標整合 | 目標引擎內實機 | 該引擎、該版本、該材質設定 | 未測的裝置 |

## 指令與證據位置

| 指令 | 產物 |
|---|---|
| `spk fidelity DIR` | `evidence/NNN/fidelity.png`（key art｜原生 setup｜差異×4） |
| `spk stress DIR [--frame …] [--only 前綴,…]` | `evidence/NNN/stress/stress_<tag>.png` |
| `spk sheet DIR --anim A [--n 12 | --times …] [--boundaries] [--over idle] [--physics] [--frame …]` | `evidence/NNN/sheets/A_<tag>.png` |
| `spk play DIR --cues … --duration S [--fps 30] [--look-keys …] [--gif F] [--mp4 F]` | `evidence/NNN/plays/<name>.png` ＋ 全部影格 |
| `spk shot DIR --anim A --time T [--also B@t#track] [--look look=x,y] [--pose "bone.rot=8"]` | `evidence/NNN/shots/…` |
| `spk compare DIR --a N --b M [--anim A --times …]` | `evidence/M/compare/…png`（前｜後｜差異）＋ 每格差異量 |
| `spk check DIR` | `build/NNN/check-report.json` |

共同選項：`--size WxH`、`--frame x,y,w,h`（**畫布像素**；用原生鏡頭拍特寫而不是裁切放大）、`--bg dark|light|both|#rrggbb`、`--bones`、`--mesh`、`--build NNN`。

每張截圖都附 `capture.json`：請求的動畫與時間、renderer 實際回報的 track 狀態、`VERIFIED/FAILED`、資產 SHA256。狀態不符會直接失敗，不會默默存圖。

## 怎麼讀圖

寫下來的觀察要能支持下一個決定，不是「看起來正常」：

- **整體**：第一眼讀到什麼姿勢與情緒？比例、重心、輪廓對不對？
- **局部**：指出具體部位——哪個關節、哪條邊、哪個時間點。把看到的現象（「0.10s 睫毛上方透出灰色圓形」）和推測的原因（「補片半透明」）分開寫。
- **時間**：預備、加速、到位、回彈、回位有沒有；哪一格突然跳。
- **代價**：原問題改善了，有沒有換來新的比例、輪廓、色差問題。

先看整張正常尺寸，再看特寫；先看正常速度（gif/mp4 或密集時序圖），再逐格看邊界。只裁局部的聯絡表不能代表整體表演。
深色與淺色底都看（`--bg both`）：髮絲邊、淺色衣緣、半透明處。

## 取樣原則

不要「每 N 格一張」就宣稱涵蓋。優先拍：動畫起點與終點、換圖／換層前後各一格（`--boundaries`）、接觸與離開、運動反向點、loop 接縫、轉場中段。
`shot/sheet` 是凍結姿勢取樣（不經過 mix 與事件，物理可用 `--physics` 從頭模擬到該時間）；`play` 才是真實播放。

## 改了什麼 → 回歸什麼

| 改動 | 至少重看 |
|---|---|
| 美術／alpha | `spk art` 兩張檢查圖、fidelity、受影響部位的 stress |
| 歸屬／層序 | fidelity、stress、有換圖的動畫 `--boundaries` |
| 網格／權重 | fidelity、check、該部位 stress 特寫、用到它的動畫 |
| 動作 | check（loop seam）、該動畫 sheet、進出 `play` |
| 控制器／混合時間 | `play` 走實際路徑（含中途打斷） |
| 圖集／打包選項 | fidelity、深淺底各一張、目標尺寸一張 |

通過後不要反覆重跑相同條件製造進度；時間留給還沒解決的視覺問題。

## 報告數字時

分開寫：數值取樣數、產生的影格數、**實際打開看過**的影格數。工具掃過 500 格不等於人看過 500 格。
差異量（`changed_px`、`max_diff`）只用來定位，不單獨當作通過／不通過。
