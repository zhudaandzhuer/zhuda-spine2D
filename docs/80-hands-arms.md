# 80 手臂深度、手掌比例與掌面

處理順序：側別與任務 → 相同解剖尺度 → 完整美術 → 肩肘腕路徑 → 投影與遮擋 → 掌面與手指 → 中途切換。
後面的步驟救不了前面的缺失；不要用淡化掩蓋形體問題。規劃可填 `templates/hand-motion-contract.example.json`。

## 先定義每一隻手

用「角色右手／畫面左側」這種寫法建立側別表，再寫每隻手的任務（揮手、握杯、壓裙…）。
把每隻手的休息、中段、最終、恢復姿勢列出：此時露出哪一面、拇指朝哪、腕口在身體哪裡、被什麼遮住。兩隻手不共用同一條翻掌進度。

## 掌部比例先於指尖

1. 標出腕中心、掌指關節線、掌主軸、同一截面的掌寬。
2. 用**腕→掌指關節的掌長**與掌寬配準；伸指圖與彎指圖不能用腕→指尖總長對齊。
3. 兩手、各姿勢在同一鏡頭同一世界尺度比較；各自 auto-fit 會掩蓋比例差。
4. 透視可以造成合理的大小差，但素材本身掌骨比例錯，不能靠縮放整條手臂補。

## 掌背與掌心是兩個表面

掌紋、魚際、指腹 vs 指甲、掌骨、指節——旋轉或鏡射不會把一面變成另一面。缺哪一面就補畫（同角色、同光、同掌部尺度），再配準腕中心與指根。
翻面做法三選一，依素材決定：補足側面 attachment、連續網格變形、或前後兩面在**窄側視角**交接。
- 不要讓 scale 穿過 0 再用負 scale 假裝翻掌。
- 不要在寬面同時交叉淡化：兩個 0.5 alpha 疊起來只有 0.75，不透明度會掉，還會出現雙指。

## 先有深度，再轉掌

可讀的順序：休息 → 向身前移出 → 肘彎、前臂縮短 → 上提 → 目標手勢 → 回收。只在畫面 x/y 上側擺再抬高，讀起來是紙片側平舉。
前臂遮住一部分上臂、袖口截面改變、長度縮短，才是「向前」的證據。縮短不能把袖口或手掌壓成針。
每次改路徑，同步檢查袖身、袖口、肘部皺折；上臂表面殘留的前臂權重會在混合時拉出折痕。

## 逐指

使用者要求每指可動時：五指都要有語意骨鏈、**真實的網格權重**、可單獨調整的動作。五根空骨或整手擺動不算。
掌面與腕根穩定，指根到指節平滑過渡；相鄰手指間的指蹼不能用「最近的手指」硬切權重。小角度的指骨旋轉也可能翻轉窄三角形——`spk check` 加上特寫 stress。

## Corrective 的邊界

拓撲、主姿勢、歸屬都合理之後，才用局部修形補體積。對加權頂點，想要的世界位移 Δw 要換回每個 influence 骨的 local：`Δlocal_i = inverse(A_i)·Δw`（A_i 是該骨世界線性矩陣）；不能把同一組 local x/y 加到方向不同的骨上。
它不能替代缺掌背、錯歸屬、錯層序或錯的手臂深度。

## 驗看

同時看全身與手部特寫，涵蓋：低手、前伸、最大縮短、窄側、掌面完全外露、回收、中途打斷。翻面附近加密取樣；只看低手與高舉兩張會漏掉抽動。
深、淺、膚色、衣色背景各看一次：指緣黑點、雙拇指、消失、腕口連續。
