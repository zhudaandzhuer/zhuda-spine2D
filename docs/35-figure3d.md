# 35 白模：3D 姿勢烘成可換皮的 2D 骨架（`spinekit.figure3d`、`motions3d`）

手 key 2D 骨頭有兩個天花板：動作只在畫的那個角度成立；肢體無法指向或遠離鏡頭。白模把姿勢放在 3D（關節角度、腳用 IK 踩在地面、會飄的東西用彈簧模擬），每一格正交投影後烘成**扁平的 2D Spine 骨架**。Runtime 端沒有 3D、沒有物理，就是普通的 Spine 4.2 JSON。

## 模型

| 3D 形狀 | 2D 影像 | Spine 通道 |
|---|---|---|
| 球（關節） | 同半徑的圓 | translate |
| 錐管（四肢、頸、鏈條） | 兩個投影關節之間的管子 | translate＋rotate＋scaleX（＝前縮） |
| 橢球（頭、胸、腰、骨盆、手、腳、配件） | 橢圓，由參考圖映射而來 | translate＋rotate＋scale＋shearY |

**視角零件**（頭、胸、骨盆、兩腳）各有 8 張圖：`_v0`…`_v7` = F、FR、R、BR、B、BL、L、FL（每 45°）。烘焙依零件自己的朝向切換；兩個視角之間把圖變形到輪廓完全吻合，只有圖的內容會「跳」。這是換皮成立的前提，見 `38-reskin.md`。

橢圓映射用 `L = S_t · U · S_ref⁻¹`（S 是橢圓矩陣的對稱平方根，U 取自零件真正的旋轉）：輪廓精確落在投影橢圓上，圖的內容跟著零件轉，而且拆成 rotate／scale／shear 是唯一且連續的。

## 身體類型與配件

`F.Body(preset)`：`hero`（標準成人＋圍巾）、`heroine`（女性＋馬尾＋裙）、`chibi`（Q 版大頭＋雙馬尾）、`brute`（壯漢＋披風＋手持棍棒）、`mascot`（吉祥物：耳朵、口鼻、尾巴、側背包）、`knight`（盾牌戰士：盾、劍、肩甲、盔纓）、`mage`（魔法師：尖帽、長袍、寬袖、法杖）。比例是倍率表 `PRESETS`，可用關鍵字覆寫：`F.Body("chibi", leg=0.5)`。

配件 `B.extras` 四種：`ell`／`tube`（剛性附著在某個部位）、`chain`（鏈條：馬尾、圍巾、尾巴；`shape="panel"` 是扁平布片；`follow_legs` 讓裙錐被大腿頂開）、`pendulum`（背帶＋包）。鏈條在烘焙時做 3D 模擬（朝休息方向的彈簧＋重力＋長度約束），loop 會跑三圈取最後一圈。

配件還可以：`views=8`（有正反面的東西，例如盾，和頭一樣有 8 張視角圖）、`plate=True`（板狀：側看視角只在真正側看時使用）、`encloses=(…)`（包住肢體的東西——長袍包腿、袖子包前臂——裡面的零件永遠畫在它下面）。

**攜帶姿勢** `HOLDS[preset]`：拿著東西的手臂在走、跑、跳、轉身時往這個姿勢靠（盾擋在身前、法杖直立）。休息姿勢也用它，所以模板圖裡的盾是正面、法杖是直的。

**類別動作**（`knight`：block／slash／bash；`mage`：cast／channel）用 `Motions.action()` 寫在站姿之上。朝左時有兩種規則：
- 走、跑、跳、轉身：`held(mirror(pose))`——動作鏡射，拿的東西放回原本那隻手。
- 類別動作：整個身體轉向左，**同一隻手**做動作（劍永遠在右手）。`mirror()` 會把動作交給另一隻手，不能用。

帶 `asym=True` 的配件（單側的包、單手的棍棒）讓身體成為**不對稱**：不能用鏡射表示朝左（包會跳到另一邊肩膀），所以每個 clip 烘兩份（`walk`、`walk_L`），由控制器依朝向選。

## 使用

```python
# art.py
F.draw(art, F.Body("heroine"), ORIGIN)            # 全部零件圖（視角零件各 8 張），由後到前，帶留白

# rig.py
B = F.Body("heroine")
F.build_rig(rig, B, ORIGIN)                       # 每個零件一根骨＋一個 slot；記錄換皮規格
motions3d.standard_set(rig, B)                    # idle walk run jump wave pick turn turntable kungfu dance ＋ 契約
```

自己寫 clip：`pose_fn(t) -> Pose`，`F.bake(rig, name, pose_fn, duration, B, loop=..., events=[...])`。從 `B.pose(heading)` 開始才會符合該身體的腳位與踝高。動作庫 `motions3d.Motions(B)` 的距離全部跟著身體縮放（步幅、起伏、跳躍高度跟腿長；站寬、側移跟髖寬；腳掌滾動跟腳長；短腿步頻較快）。

| `Pose` 欄位 | 意義 |
|---|---|
| `heading`、`root` | 朝向（0 面向鏡頭、+90 面向畫面右）；身體地面點的世界位置 |
| `px, py, pz`；`pyaw, ppitch, proll` | 骨盆位移（相對站姿）與旋轉。pitch>0 前傾、yaw>0 左轉、roll>0 向角色右側傾 |
| `syaw…`／`hyaw…` | 胸相對骨盆（分兩節）／頭相對胸 |
| `arm[L|R] = {flex, abd, twist, elbow}` | 肩前擺、外展、上臂自轉（決定手肘往哪彎）、手肘 |
| `foot[L|R] = {x, y, z, pitch, yaw, world, pole}` | 腳踝的 IK 目標；`pole` 指定膝蓋方向 |

`F.mirror(pose)` 給鏡像姿勢（不交換身體的左右構造）。

## 逐姿勢編排：`Choreo`

```python
c = F.Choreo(B, heading=90)
c.key(0.45, heading=75, py=-30, armL=GUARD_L, footL=("step", 72, 20, 0), footR=("step", -72, -24, -40))
c.key(1.56, footR=("fk", 95, 6, 0, 118, 0))                          # 提膝
c.key(1.70, ease="snap", footR=("fk", 94, 4, 0, 6, -20))             # 前踢
```

腳：`("step", fwd, lat[, yaw, lift])`、`("pivot", yaw)`、`("fk", flex, abd, rot, knee[, ankle])`、不寫＝維持（踩著的腳一格都不動）。`ease` 是到達方式（`snap` 出拳出腿）。單腳支撐的轉身或踢腿先 `root=c.spot("L"), px=-髖寬`。完整例子：`motions3d.Motions._build_kungfu`。

## 邊界處理（烘焙時自動做，結果寫進 `build/NNN/bake-report.json`）

| 狀況 | 處理 |
|---|---|
| 腳的目標超出腿長 | 先降骨盆，還不夠就把身體移向那隻腳（`reach_guard`）。五種身體的全部 clip 殘餘為 0（自測）|
| 肢體正對鏡頭（投影長度趨近 0） | scaleX 夾在下限、角度沿用上一格 |
| 橢圓經過正圓 | 用 shear 分解，不換軸、不跳 90° |
| 視角邊界附近來回 | 遲滯（偏離目前視角中心 >27.5° 才換）＋最短停留 0.1 秒；仍有「去了馬上回來」的記在 `flicker` |
| 身體大幅前彎時判斷朝向 | 朝向取零件的側向軸，前彎不影響 |
| 視角切換瞬間 | 骨頭變形與換圖在同一個時間點、以 stepped key 寫出（時間先對齊到 4 位小數）|
| 深度相近的零件前後閃爍 | draw order 用遲滯排序；key 只列有移動的 slot |
| loop 接縫 | 最後一個取樣直接用第一個；配件模擬跑三圈 |
| 不對稱身體朝左 | 不鏡射，烘 `_L` 版本；預覽器、步態檢查都認得 |
| key 太多 | 每條曲線在容許誤差內刪點（位置 0.35px、角度 0.35°、縮放 0.004）|
| 管狀零件在休息姿勢被前縮（指向鏡頭的劍、法杖） | 圖一律畫成真實長度，動畫只會把它縮短，不會拉長 |
| 薄片側看（盾、劍刃、披風、耳朵） | 改成對齊長軸（薄片沒有內容可轉）；shear 夾在 ±85°，不會翻面 |
| 板狀零件剛轉離側看 | 側看視角只用在 ±10° 內，其餘交給 3/4 視角（只會被壓窄，不會被拉寬）|
| 側躺的零件（橫在前臂上的盾）判斷朝向 | 朝向取「面向軸」與「側向軸」中較水平的那一個 |
| 肢體穿出包住它的配件（腿穿出長袍） | `encloses`：draw order 規則，不靠深度 |
| 動畫尾端的事件 | clip 被混出時事件不會送達；`flip` 一律放在轉身中點 |

正面表演（看板、虛擬主播）：面向鏡頭的 clip、臉部零件、即時參數、runtime 物理頭髮，見 `39-front-performer.md`。

## 限制

- **動作中途被打斷**：clip 之間的混合是逐骨線性內插。兩個 clip 在混合當下若處於不同視角，頭或軀幹會短暫變形。標準動作都從同一個站姿開始、結束，所以播完再切不會有事；中途硬切會。
- **四肢只有一張圖**，繞自身軸的方向不分；上下方向（俯視、仰視）沒有視角圖，大幅前彎時用同一張圖壓扁。
- **配件不碰撞身體**（裙子有大腿頂開的近似，披風、馬尾會穿過手臂）。
- JSON 大：十個 clip 約 3 MB，不對稱身體約 5.5 MB。
- 沒有手指、表情；沒有拿取道具或兩個角色接觸的約束。
