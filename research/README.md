# 研究紀錄

拿真實角色驗證 zhuda-spine2D 的方法。這裡只有程式與工作日誌，角色美術、生成圖、驗收截圖都沒有放進 repo。
腳本裡的 `work/...` 路徑指的是原本工作目錄的結構；要重跑需要自備美術並設定 `KIT`、`PLAYWRIGHT_MODULE`、`CHROME_PATH`（見 `zhuda/env.sh`）。

| 資料夾 | 內容 |
|---|---|
| `zhuda/` | 用豬大替八個白模換皮；從設計稿直接做正面、半身（表情、揮手、抬頭低頭、轉身）、戰鬥（木棒＋法術）的骨骼版本 |
| `miyazi/` | 米丫子半身虛擬主播（表情狀態、對嘴、物理頭髮） |
| `miyazi_full/` | 米丫子全身：跑、跳、徒手攻擊、撿東西。`WORKLOG.md` 記錄每一輪自我稽核找到的問題、修法與仍未過的數值閘門 |

主要結論（細節在各 WORKLOG）：
- 白模換皮會讓比例特殊的角色（矮胖的豬大）變形；比例特殊的角色要從它自己的設計稿綁定。
- 單張主視覺切零件，大動作時一定會露出原圖沒畫的地方（肩頭、胯下、大腿上端）；要靠補畫的隱藏層、零件歸屬規則、球關節式的零件端點來處理。
- 數值閘門（三角形翻轉）在膝、肘大彎曲處仍未歸零。
